## 현재 동작과 유지 조건

### 입력과 처리

- Ubuntu 24.04 LTS x86_64/WSL의 Linux 파일시스템에서 실행합니다. API는 음성 모델을 로드하지 않습니다. 의존성은 `uv.lock`·웹 `package-lock.json`, 모델은 manifest로 고정합니다.
- 입력은 최대 2,000,000,000바이트·7,200초입니다. 언어·화자는 자동이며 화자 상한은 12명입니다. 여러 오디오 트랙은 선택을 요구합니다.
- `large-v3-turbo` CPU INT8·pyannote community-1을 사용합니다. 원본 시간축·단어·화자 ID를 유지하고, 정렬 실패 시 원문 구간 시각으로 대체합니다. 근거 없는 자동 화자 병합은 하지 않습니다.
- 분석과 AI 재생성은 독립 FIFO에서 각각 한 건씩 처리합니다. 차단된 앞 작업을 건너뛰지 않으며, 재생성은 저장된 전사만 사용합니다. 같은 AI 공급자의 호출은 두 큐에 걸쳐 하나씩 실행합니다.
- 입력·설정·모델 지문과 해시가 맞는 완료 단계만 재사용합니다. 저장 직전 attempt·취소·삭제를 검사하고, 취소는 자식 종료 후 확정합니다. 원본·과거 결과·수정본은 덮어쓰지 않습니다.
- YouTube는 허가된 공개/일부 공개 단일 영상 전체를 지원합니다. 로그인·쿠키·진행 중 라이브·재생목록·DRM·직접 HTTPS 음성 형식이 없는 자료는 제외합니다. 고정 yt-dlp/EJS/Deno·bubblewrap 경계를 유지하며 부분 다운로드를 전체 성공으로 취급하지 않습니다.

### 결과와 화면

- 일반 목록·입력·편집은 키 없이, 설정·진단은 소유자 인증 후 사용합니다. 설정 순서는 AI 연결 및 선택 → 자료 보관 → 실행 환경과 사용량입니다.
- 새 입력의 AI 생성은 활성입니다. 빈 제목은 같은 생성 응답에서 정하고 YouTube는 원본 제목을 사용합니다. 과거 전사 전용 자료는 열람·업데이트만으로 외부 전송하지 않습니다.
- 회의록 논제 제목은 2~6단어 명사구·최대 60자를 지향합니다. 재논의는 다른 논제를 거쳐 돌아온 경우입니다. 개별 근거 보완을 사용자 편집본 저장의 필수 조건으로 삼지 않습니다.
- 최초 회의록은 `초안`, 이후 `버전02_0927`처럼 번호와 KST 저장일을 표시합니다. 재생성은 새 기본 버전이지만 생성 중 저장한 수정본·새 전사는 덮어쓰지 않습니다. 편집 중이 아닐 때 최신 결과를 반영합니다.
- 영상은 읽기 전용·최신 결과 표시이며 내부 이력은 보존합니다. 수치·주장·전망은 관련 주제에 통합합니다. 음성 재생기는 요약 위, 원본 영상 링크는 전체에 하나입니다.
- 전사 열람/교정·화자 편집·최종 확정·영상 버전 선택 UI는 제공하지 않습니다. 호환 데이터/API는 보존합니다. 취소·재생성·삭제는 사이트 모달, 미저장 상태의 탭 이탈은 브라우저 경고로 확인합니다.
- 내보내기는 회의록 선택 버전·영상 표시 결과와 일치합니다. 파일명은 `minutes_verNN_MMDD` / `summary_verNN_MMDD`의 `.md/.txt`입니다. UTF-8·CRLF를 사용하고 재생 시작 시각만 제외합니다. 날짜·수치·특수문자는 보존하며 Markdown에만 필요한 이스케이프를 적용합니다.
- 읽기/내보내기는 문장 끝에서 줄바꿈하되 소수점·URL·약어·문단을 보존합니다. 저장 원문·편집 입력·제목은 바꾸지 않습니다.

### AI 공급자와 사용 한도

- 하나의 활성 AI를 저장하며 준비되지 않은 공급자는 선택할 수 없습니다. 자동 공급자/모델/유료 API 폴백은 없습니다. STT·정렬·임베딩·검색·내보내기를 외부 AI 호출로 바꾸지 않습니다.
- 업로드 완료·YouTube 등록·재생성 등록 트랜잭션에서 공급자·모델·정책 revision·프롬프트/schema/어댑터·문맥·호출 한도를 고정합니다. 재시도·중복 요청·청크·보정도 이를 유지합니다. 새 AI는 새 요청부터 적용합니다. 비밀은 snapshot·identity에 넣지 않습니다.
- 응답은 공통 문서 스키마·근거·한국어·숫자/날짜 기준으로 검증합니다. 긴 전사는 전체를 분할/통합하며 뒤를 버리지 않습니다. Gemini의 추가 스키마 문자열도 입력 예산에 포함합니다.
- 사용 한도는 snapshot과 별도의 현재 관리자 정책으로 호출 직전 검사합니다. 영속 예약은 실패·취소·재시작·회의 삭제로 초기화하지 않습니다. 예산 대기 작업은 한도 인상·갱신·분당 창 만료 후 FIFO와 중간 결과를 유지해 자동 재개하며 원문 자동 삭제에서 보호합니다.
- Codex·Claude는 진행 중 호출 하나의 초과와 완성된 결과를 보존합니다. 사용량 미확정 호출은 예약량을 유지합니다. Gemini는 실패·재시도·청크마다 1회이며 주간 토큰으로 차단하지 않지만 토큰 기록은 보존합니다.
- Gemini 10 RPD·2 RPM은 [3.6 무료 계정 실측 20 RPD·5 RPM](https://aiplug.work/en/blog/gemini-free-tier-limits)의 절반 수준 추정입니다. [공식 한도](https://ai.google.dev/gemini-api/docs/rate-limits)는 프로젝트별이며 현재 계정·3.8의 보장값이 아닙니다. TPM과 다른 앱의 프로젝트 사용량은 관리하지 않습니다.
- Gemini 429는 자동 반복하지 않습니다. 일시적 서버/네트워크 오류는 최대 2회 재시도하며 서버가 요구한 대기가 30초를 넘으면 자동 진행하지 않습니다. 진단에는 허용된 오류 분류·숫자만 기록합니다.
- Claude의 앱 문맥/출력 예약은 보수적인 200k/32k입니다. 로컬 버전·로그인 진단은 30초 재사용하며 원격 모델 접근·남은 구독량·실제 생성 성공을 보장하지 않습니다.

### 보관·비밀·업그레이드

- 기본 보관은 수신 완료일부터 미디어 7일, 전사/정렬/임베딩 30일, 결과 영구입니다. 처리/예산 대기 자료는 보호하고 사용자 직접 취소·삭제는 허용합니다. 원문 만료 후에도 결과 편집·열람·내보내기는 가능합니다.
- Gemini 키는 `<config_dir>/.apikey/gemini.json` 한 곳에 권한 0600(디렉터리 0700)으로 보관합니다. revision·잠금·원자 교체를 사용하며 입력 실패가 기존 키를 훼손하지 않습니다. 링크·공개 경로를 거부합니다. 같은 OS 사용자/root를 막는 암호화는 아닙니다.
- 키 조회·복사 API는 없으며 저장·이탈·로그아웃·세션 만료 때 입력을 지웁니다. 소유자·CSRF·revision 검사를 적용하고 422·로그·CLI 출력·브라우저 저장소에 원문을 노출하지 않습니다. 로컬 키 삭제는 Google 키 폐기가 아닙니다.
- CLI는 전용 HOME·인증 디렉터리·임시 cwd·제한 환경에서 실행합니다. 개발 인증·도구·MCP/hooks·임의 endpoint/API 키를 상속하지 않습니다. Claude 구독 인증을 막는 `--bare`나 권한 우회 옵션을 대체책으로 사용하지 않습니다.
- 0013~0014는 토큰 원장을 보존·분리했고, 0015는 기존 기본 Gemini 3.5를 3.8로 이전했습니다. 0016은 태평양 날짜에 맞는 요청 원장을 추가하며 시각 미상 최근 호출을 보수적으로 합산합니다. 0017은 기존 기본 Sonnet만 Opus로 바꾸고 사용자 지정 모델·활성 공급자는 유지합니다.
- 이전 작업 설정을 복구할 수 없거나 어댑터 계약이 달라진 작업은 명확히 차단합니다. 기존 완료본은 유지하고, 저장된 전사로 새 생성할 수 있습니다. 인증/준비 캐시는 복원·이전 후 재검사합니다.

재개 시 위 미완료 항목만 확인하고, 실제 호출은 새 유한 예산을 기록합니다. 과거 실패·소진 예산은 초기화하지 않습니다. 최신 범위 결과는 `.workflow/reviews/M3-JSON-002`, `M3-OPUS-002`, `M3-RUNTIME-001`, 종합 색인은 `.workflow/evidence/m3/execution-index.json`에 있습니다. 색인의 오래된 코드 지문을 현재 PASS로 간주하지 않습니다.

자연 12인 회의의 CER/WER/DER는 평가하지 않았으며 혼용·겹친 발화·근거 의미에는 사람의 검토가 필요합니다. 약 3분 한국어/영어 입력의 과거 CPU 실측은 Ryzen 5800X·WSL 24GiB/8vCPU·앱 4스레드에서 약 224/214초였습니다. GPU·실시간 STT·다중 사용자·외부 발행은 범위 밖입니다. **120분 soak는 완료 조건에서 제외하며 새 사용자 지시에만 실행합니다.**
