# 로컬 회의록

Ubuntu 24.04 x86_64용 개인 로컬 웹 앱입니다. Windows에서는 WSL Ubuntu에서 실행하고 브라우저로 사용합니다. CPU 전사·화자 구분 후 텍스트·메타데이터만 별도 구독 Codex CLI로 보내 한글 회의록이나 영상 요약을 만듭니다. 새 웹 입력은 AI 생성을 사용하며, 과거 전사 전용 자료를 업데이트만으로 전송하지 않습니다. 음성·영상·화자 임베딩은 로컬에 남습니다.

## 구현된 기능

- 음성·영상 업로드, 최대 2GB(2,000,000,000바이트)·120분, 오디오 트랙 선택, 언어·발화자 자동 인식(1~12명).
- `large-v3-turbo` CPU INT8 전사, 한·영 정렬, pyannote 자동 화자 구분과 문장·발언 단위 읽기 전사.
- 영속 FIFO, 처리 상태, 취소·재시도·중단 복구.
- 논제 중심 한글 회의록과 시작 시각, 문서 편집·저장·버전 관리.
- 영상 파일·YouTube 링크 입력, 회의와 공유하는 대기열, 읽기 전용 영상 요약과 주제별 시작 위치. M2 구현·범위 검수와 짧은 허가 영상의 실제 음성 획득·시간 매핑·설치 인수를 완료했습니다.
- 검색, 근거 음성 재생, Markdown/텍스트 내보내기, 삭제·보관 설정.
- 키 없는 로컬 사용·설정/진단 소유자 인증, 설치·백업/복원, 선택적 systemd 사용자 서비스.

MVP 검증은 완료됐으며 이후 작업 상태는 [마일스톤](docs/milestone.md)에 기록합니다. Git에는 소스·테스트·고정 의존성·문서·이용 고지가 포함됩니다. 개인 실행 증거 `.workflow`, 회의 데이터, 모델 가중치, 로그인 정보, 생성 번들은 포함되지 않습니다.

## 설치·실행

Ubuntu/WSL의 Linux 파일시스템에 저장소를 checkout하거나 번들을 풀고, 해당 디렉터리에서 일반 사용자로 실행합니다. `/mnt/c`·`/mnt/d` 설치는 지원하지 않습니다. 준비 기준은 RAM 32GB·CPU 6코어 이상이며 처리 속도는 장비에 따라 달라집니다.

```bash
bash scripts/install-ubuntu.sh --system-plan  # 필요한 관리자 패키지 명령 확인
# 필요한 시스템 패키지를 설치한 뒤:
bash scripts/install-ubuntu.sh               # 고정 도구·환경 설치, 필요 시 웹 빌드
.venv/bin/hf auth login
bash scripts/prepare-models.sh --accept-model-terms
bash scripts/login-codex.sh                  # 별도 런타임 구독 로그인
bash scripts/doctor.sh
bash scripts/run.sh
```

모델 준비 전 [pyannote 이용조건](https://huggingface.co/pyannote/speaker-diarization-community-1)을 소유자가 확인·동의해야 합니다. 옵션은 웹 동의나 로그인을 대신하지 않습니다. 모델 리비전·해시는 `src/meeting_minutes/model_manifest.json`, 의존성·모델 고지는 [THIRD_PARTY](notices/THIRD_PARTY.md)에 있습니다.

브라우저에서 `http://127.0.0.1:8765`를 열면 키 없이 회의 목록·업로드·편집을 사용할 수 있습니다. 설정·진단에 들어갈 때만 `~/.config/local-meeting-minutes/owner-key`로 로그인합니다. 로그아웃해도 일반 작업은 계속 사용할 수 있습니다. 키·토큰을 채팅이나 Git에 넣지 마세요. Windows 실행 진입점은 `powershell -File scripts/dev-windows.ps1 -Distro Ubuntu -Repo <Linux-절대경로>`입니다.

## 사용과 운영

새 회의에서 파일·제목·회의 일시를 입력합니다. 일시는 현재 한국 시간으로 시작하며 언어와 화자 수는 자동 인식합니다. 연결된 AI 생성은 항상 활성입니다. 업로드 응답을 받지 못해 새로고침했다면 같은 파일을 다시 선택해 이어갑니다. 차단된 앞 작업은 재시도·전사만 종료·취소로 해소합니다. 상세 화면에서 논제와 요약을 읽고 시작 시각으로 음성을 확인합니다. 회의록 편집에서 논제·결정·담당자를 보완하고 수정본을 새 버전으로 저장합니다. 수정과 재생성은 새 버전으로 남습니다.

영상 요약 메뉴에서는 파일 또는 사용할 권한이 있는 YouTube 단일 영상 링크를 등록합니다. 새 회의·영상 분석은 하나의 FIFO에서 처리하며, 저장된 전사를 사용하는 AI 재생성은 별도 FIFO에서 동시에 한 건씩 처리합니다. 요약본은 편집·확정 없이 읽고 내보내며, 재생성은 새 초안으로 남습니다. 주제 위치에서 로컬 음성을 듣거나 YouTube 원본 영상를 열 수 있고 음성 만료 후에도 원본 링크는 남습니다.

YouTube는 공개·일부 공개의 종료된 단일 영상 전체를 대상으로 합니다. 로그인·쿠키가 필요한 자료, 실시간 영상, 재생목록 자체, DRM 및 직접 HTTPS 음성 형식이 없는 영상은 지원하지 않습니다. 최대 길이·크기는 파일 입력과 같으며 접근 실패 시 허가된 파일을 직접 올릴 수 있습니다. 설치기는 고정된 yt-dlp·EJS·Deno와 bubblewrap을 준비하며, 진단에서 격리 실행 가능 여부를 확인합니다. 다운로드는 인증 파일을 노출하지 않는 격리 환경과 제한된 HTTPS 전송 경로를 사용합니다.

```bash
bash scripts/stop.sh
bash scripts/backup.sh /absolute/new-backup.tar.gz
bash scripts/restore.sh /absolute/new-backup.tar.gz /absolute/new-data-directory
MINUTES_DATA_DIR=/absolute/new-data-directory bash scripts/run.sh
bash scripts/install-service.sh  # 서비스 파일 생성; 활성화는 출력 안내를 따름
```

백업 전 앱을 정지합니다. 백업은 인증·로그인 세션을 제외하고 회의 내용을 포함합니다. 복원은 파일 크기·해시 manifest 검사 후 존재하지 않는 새 경로에만 수행합니다. 기본 자동 보관은 원본·재생용 음성/영상 7일, 전사·정렬·화자 임베딩 30일입니다. 회의록·요약본과 버전은 영구 보존합니다. 입력 수신 완료일부터 계산하고 처리 중인 자료는 종료 후 정리합니다. 기존 사용자 정책은 보존하며 기존 자료에는 이전 시점의 일회성 유예를 적용합니다. 원문 만료 후에도 회의록 편집·저장과 두 종류 결과의 열람·내보내기가 가능하지만 재생·원문 확인·원문 기반 재생성은 해당 자료가 남아 있을 때만 가능합니다. 별도 백업은 앱 삭제와 함께 지워지지 않습니다.

기본 데이터·설정·캐시는 HOME/XDG를 따르며 `MINUTES_DATA_DIR`, `MINUTES_CONFIG_DIR`, `MINUTES_CACHE_DIR`로 변경할 수 있습니다. 기본 구독 인증 경로는 `~/.local/share/local-meeting-minutes/codex-home`입니다. 다른 장비/사용자에서는 인증을 복사하지 않고 다시 로그인합니다.

## 개발·검증

설치 후 도구 환경을 읽고 개발 의존성을 준비합니다.

```bash
source "${XDG_DATA_HOME:-$HOME/.local/share}/local-meeting-minutes/toolchain/env.sh"
uv sync --frozen
(cd apps/web && npm ci)
bash scripts/check.sh affected tests/test_foundation.py
```

[작업 규약](docs/workflow.md)에 전체 검사·검수·증거 관리 절차가 있습니다.

회의록의 재논의 시각은 다른 논제를 거쳐 돌아온 경우에만 표시합니다. 웹에서는 시각으로 음성을 탐색하고, Markdown·텍스트 내보내기에서는 논의 시작 시각을 제외합니다. 생성과 내보내기는 `AI를 사용한 요약 회의록 생성` 박스에 있으며 최종 확정 버튼은 제공하지 않습니다.

웹에서 다운로드하는 텍스트·Markdown 파일은 Windows 사용을 위해 UTF-8·CRLF로 제공한다. 저장소 소스·문서는 기존 LF 규칙을 유지한다.

재생성·자료 삭제·보관 정책·미저장 변경 확인은 사이트 모달을 사용하며 취소/Escape로 작업을 중단한다. 탭 닫기·새로고침의 미저장 경고는 브라우저 기본 보호를 유지한다. 실제 사용 서버는 작업 처리기를 활성화해야 대기열이 실행된다. `MINUTES_WORKER_ENABLED=false`는 격리된 화면 시험에서만 사용한다.

재생성은 음성을 다시 분석하지 않고 저장된 전사로 AI 요약만 별도 실행한다. 명시적 재생성 결과는 새 기본 버전이 되며 이전 수정본은 보존한다. 생성 도중 저장된 별도 수정본이나 새 전사는 덮어쓰지 않는다. 편집 중이 아니면 완료된 최신 결과를 자동으로 표시하고, 내보내기는 현재 선택한 버전을 사용한다. 최초 버전만 초안으로 표기한다. 제목을 비운 파일은 요약 생성 시 AI 제목을 저장하며, 제목을 비운 YouTube는 원본 제목을 사용한다. 취소 전 사이트 모달로 확인한다.

영상 요약 상세는 회의록과 같은 본문·주제 카드·버튼 스타일을 사용하며 줄바꿈을 보존한다. 음성 재생기는 핵심 요약 위에 둔다. 원본 영상 링크는 전체에 하나, 요약 재생성·텍스트·Markdown 내보내기는 생성 박스에 모은다. 영상의 버전 선택·표시는 제거하고 최신 요약만 제공한다. 내부 저장 이력은 보존하며 내보내기는 화면에 표시된 요약에 연결된다.

내보내기 파일명은 회의록 `minutes_verNN_MMDD.md/txt`, 영상 요약 `summary_verNN_MMDD.md/txt`이며 선택한 결과의 버전 번호와 저장일(KST)을 사용한다. 본문과 파일명은 같은 결과를 기준으로 만든다.

영상 요약은 별도의 수치·주장·전망 목록 없이 주요 주제에 내용을 통합한다. 새 생성은 각 주제 본문에 수치·단위·기간과 발언 주체를 보존한다. 기존 저장본은 변경하지 않고 별도 주장 목록의 표시·내보내기만 제외하며 새 구성으로 정리하려면 요약을 재생성한다. 회의록과 영상 모두 텍스트·Markdown 내보내기에서 재생 시작 시각을 제외하고 웹의 시각·재생 버튼은 유지한다.

회의록·영상 요약의 읽기 화면과 텍스트·Markdown 내보내기는 마침표로 끝나는 문장을 줄바꿈한다. 소수점·URL·일반적인 영문 약어와 기존 문단을 보존하며 저장 원문·편집 입력·제목은 변경하지 않는다.
